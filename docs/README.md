# Kuro Gamification — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something, doing something, looking something up, and understanding why are different needs, so they live on different pages. Only the kinds that have content are listed here. Every guide except Troubleshooting also exists in German (`.de.md`).

**New here?** → [Getting started](getting-started.en.md) — from the install to your first XP and your first loot.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.en.md)** ([DE](getting-started.de.md)) | Learning-oriented. Point the plugin at your daily notes, tick a checkbox, redeem your first loot. |
| **[Customization](customization.en.md)** ([DE](customization.de.md)) | Task-oriented. Swap loot and lore with packs, including a ready-to-paste LLM prompt. |
| **[Aesthetic CSS](aesthetic-css.en.md)** ([DE](aesthetic-css.de.md))| Task-oriented. Install the optional gothic-cyberpunk CRT look. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "No data yet", the empty sidebar, a pack that will not import, the companion chat that cannot reach its endpoint. |
| **[Manual](manual.en.md)** ([DE](manual.de.md)) | Reference. Every setting, command and rule in one place. |
| **[Design Philosophy](philosophy.en.md)** ([DE](philosophy.de.md)) | Explanation. Why the plugin is built the way it is: freeze tokens, no re-rolls, everything escalating off by default. |

The [README](https://github.com/johannes-kaindl/kuro-gamification/blob/main/README.md) gives the overview, the install routes and the settings summary.
